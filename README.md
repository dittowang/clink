# Clink

A 3D beach-table drink-merge game. Slide drinks down a plank table on the
sand, bank them off the rails, merge three of a kind into something heavier —
from a juice box to a glass drink dispenser — across a day at the beach.

Three.js + Rapier. Everything you see and hear — every drink, texture, wave,
and clink — is generated by code at load. No models, no images, no samples.

**Play it now:** https://dittowang.github.io/clink/

## Run

```bash
npm install && npm run dev
```

That's it. `npm run build` emits a static `dist/` folder for any host.

## Play

- **Press anywhere, swipe in the direction you want, release** — every push
  fires with enough strength to reach the far rail, so aim is the whole game
  (up to 35° either side). The arrow shows the path and the ring marks the
  first thing it will hit; after a side rail, a fainter line previews the
  bank. Heavy drinks plow through what they meet, light ones bounce off.
- **Three of a kind touching** merge into the next tier. Chains within a
  second multiply ×1.5 per link.
- **Endless is a shift at the beach bar**: the card at the top is the
  current order — make that drink and it's carried off the table for 3×
  points plus a tip for spare pushes. Run out of pushes and the customer
  leaves a mess near the foul line. Every three orders the bar heats up and
  deals bigger drinks.
- Bank shots off the far and side rails are legal. The near edge is open —
  drinks that go over are lost to the sand.
- A drink resting across the **foul line** for a couple of seconds ends the
  run.
- Four chapters (morning → noon → golden hour → night) of six hand-designed
  puzzles each — a fixed hand of drinks, a layout, a par — plus Endless.
  Solving four puzzles of a chapter unlocks the next.

## Tech notes

- Exactly two runtime dependencies: `three` and `@dimforge/rapier3d-compat`.
- Physics steps at a fixed 1/120 s with render-side pose interpolation.
- The mass ladder — the one table that drives every impulse, stop distance,
  impact sound, and camera nudge — lives in
  [`src/config/massLadder.ts`](src/config/massLadder.ts), one comment per row.
- Debug/QA scenes: `?scene=lineup` (product shoot of all twelve drinks,
  `&silhouette=1` for the ID test), `?scene=ladder` (identical-pull stop
  distances per tier, logged), `?scene=probe&tier=N` (single-drink
  turntable). `?harness=1` makes time deterministic for the Playwright
  capture harness (`node scripts/capture.mjs --help` style usage in the
  script header).
